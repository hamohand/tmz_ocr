📌 Qu'est-ce que Dawaliw-ⵣ-OCR ?

Dawaliw-ⵣ-OCR est un outil qui convertit automatiquement vos documents amazighs (PDF, photos, scans) en texte numérique que vous pouvez copier, modifier et enregistrer.

Il reconnaît le tamazight en écriture latine, y compris les caractères spéciaux :

ɣ
ḥ
ɛ
ḍ
ẓ
ṭ
ṣ
ṛ
č
ǧ

🚀 Installation

L'installation se fait une seule fois. Suivez les étapes dans l'ordre.

Étape 1 — Installer Python

Python est le moteur de l'application.

1
Allez sur python.org/downloads et téléchargez Python (version 3.10 ou plus récente).
2
Lancez l'installateur. ⚠️ Cochez la case « Add Python to PATH » en bas de la fenêtre, puis cliquez sur « Install Now ».

Étape 2 — Installer Tesseract OCR

Tesseract est le moteur de reconnaissance de texte.

3
Windows : Téléchargez l'installateur sur github.com/UB-Mannheim/tesseract/wiki. Installez avec les options par défaut.

Linux/Mac : Ouvrez un terminal et tapez : 
sudo apt install tesseract-ocr    # Ubuntu/Debian
brew install tesseract              # Mac

Étape 3 — Installer Dawaliw-ⵣ-OCR

4
Téléchargez et décompressez le dossier Dawaliw-ⵣ-OCR à l'endroit de votre choix.
5
Ouvrez un terminal (ou l'Invite de commandes Windows) dans le dossier de l'application, puis tapez : 
pip install fastapi uvicorn pillow python-multipart pymupdf
Attendez que l'installation se termine.
💡 C'est tout ! L'installation est terminée. Vous n'aurez plus besoin de refaire ces étapes.

▶️ Lancer l'application

À chaque fois que vous voulez utiliser Dawaliw-ⵣ-OCR :

1
Ouvrez un terminal dans le dossier de l'application.
Astuce Windows : ouvrez le dossier dans l'Explorateur, tapez cmd dans la barre d'adresse, puis Entrée.
2
Tapez cette commande : 
python -m uvicorn api.app:app --host 0.0.0.0 --port 8000
3
Ouvrez votre navigateur web et allez à l'adresse : 
http://localhost:8000
💡 Ne fermez pas la fenêtre du terminal tant que vous utilisez l'application.

📖 Comment utiliser

Convertir un document

1
Glissez votre fichier (PDF ou image) dans la zone de dépôt, ou cliquez dessus pour le sélectionner.
2
Si votre document est sur 2 colonnes (comme un dictionnaire), cochez la case « Document à 2 colonnes ».
3
Cliquez sur « Convertir en texte ⵣ ». La conversion peut prendre quelques secondes à quelques minutes selon la taille du document.
4
Le texte apparaît. Vous pouvez le copier (📋) ou le télécharger (💾) en fichier .txt.

Comprendre les indicateurs de qualité

Après la conversion, l'application affiche :

  • Qualité caractères latins — fiabilité de la reconnaissance des lettres ordinaires (a, b, c...)
  • Qualité caractères amazighs ⵣ — fiabilité de la reconnaissance des lettres spéciales (ɣ, ḥ, ɛ, ḍ...)
  • Caractères reconnus — la liste des lettres amazighes trouvées dans le document

Les couleurs indiquent :

  • ■ Vert = très bonne qualité (≥ 90%)
  • ■ Orange = qualité correcte (70-90%)
  • ■ Rouge = à vérifier (< 70%)

💡 Conseils pour de meilleurs résultats

  • Scannez en haute qualité — 300 DPI minimum pour les documents imprimés.
  • Bonne luminosité — si vous prenez une photo, assurez-vous d'un bon éclairage sans ombres.
  • Image droite — évitez les pages inclinées ou tordues.
  • Documents récents — les documents imprimés récemment sont mieux reconnus que les anciens.
  • Formats acceptés — PDF, JPG, PNG, TIFF.
⚠️ Les documents très anciens, manuscrits, ou en mauvais état peuvent donner des résultats moins fiables. Vérifiez toujours le texte obtenu.

❓ Questions fréquentes

L'application ne démarre pas

Vérifiez que Python est bien installé en tapant python --version dans le terminal. Si la commande n'est pas reconnue, réinstallez Python en cochant « Add to PATH ».

Le texte reconnu contient des erreurs

C'est normal pour les documents anciens ou de mauvaise qualité. L'OCR n'est pas parfait. Relisez et corrigez le texte manuellement. Les caractères latins ordinaires sont généralement mieux reconnus que les caractères amazighs spéciaux.

Combien de temps prend la conversion ?

Une page prend environ 5 à 30 secondes selon la qualité et la taille de l'image. Un PDF de plusieurs pages sera plus long. Pour les PDF, l'application teste automatiquement 2 résolutions pour obtenir le meilleur résultat.

Est-ce que mes documents sont envoyés sur Internet ?

Non. Tout le traitement se fait sur votre ordinateur. Aucun document n'est envoyé à l'extérieur. Vos données restent privées.
